Human in the loop - AI agent approval

Webhook Action API

Pause an automated workflow for a human decision. Define a form, send its hosted URL to a reviewer and poll a structured response - without building a frontend or backend.

  • No API key
  • Hosted form
  • Structured response
  • 24-hour expiry

Create an action

POST/webhook_action

https://aisenseapi.com/services/v1/webhook_action

A complete human-in-the-loop pattern

The API handles the temporary state, the hosted form and the polling endpoint. Your automation only needs to create the action, deliver the form URL to a person and wait until the status changes from pending to answered.

  1. Describe the decision

    POST a title, optional description and one or more form fields.

  2. Send the form URL

    Share it through email, Slack, a ticket or any channel the reviewer already uses.

  3. Poll the result URL

    Continue the workflow when a structured response appears.

Create an approval form

curl -X POST https://aisenseapi.com/services/v1/webhook_action \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Approve deployment to production?",
    "description": "Review the release before it continues.",
    "fields": [
      {
        "type": "radio",
        "name": "decision",
        "label": "Decision",
        "required": true,
        "options": [
          {"value":"approve","label":"Approve"},
          {"value":"reject","label":"Reject"}
        ]
      },
      {"type":"textarea","name":"comment","label":"Notes","max_length":500}
    ]
  }'
{
  "ok": true,
  "action_id": "9e0e6d3b-1a45-44c5-9e0b-92f5f3bdb2f1",
  "form_url": "https://aisenseapi.com/services/v1/webhook_action/9e0e6d3b-.../form",
  "result_url": "https://aisenseapi.com/services/v1/webhook_action/9e0e6d3b-...",
  "expire_timestamp": 1786959912,
  "expire_datetime": "2026-08-17T09:45:12Z"
}

Supported form fields

TypeBest forImportant properties
radioOne visible choice from a short listoptions, required
selectOne choice from a longer listoptions, required
textShort free-form answersmax_length, required
textareaComments, reasons and instructionsmax_length, required
checkboxConfirmation or multiple independent choicesoptions, required

Options may be plain strings or objects with separate value and label properties.

Poll for the answer

curl "{result_url}"

Before submission, status is pending and response is null. After submission:

{
  "ok": true,
  "action_id": "9e0e6d3b-...",
  "status": "answered",
  "answered_at_datetime": "2026-08-16T15:13:20Z",
  "response": {
    "decision": "approve",
    "comment": "Looks good"
  }
}

Useful approval workflows

Deployment gates

Require an explicit go/no-go decision before production changes.

AI agent escalation

Ask a person when an agent reaches a risky or ambiguous decision.

Content review

Collect approval, rejection and revision notes in a predictable shape.

Exception handling

Pause an automation when a transaction or document needs human judgment.

Expiry and security

Actions expire after 24 hours. Design the calling workflow to handle an unanswered or expired action instead of polling forever.

The form and result URLs are unguessable capability URLs. Send them only to the intended reviewer. Do not use the service for confidential data that requires long-term retention or account-based access control.
