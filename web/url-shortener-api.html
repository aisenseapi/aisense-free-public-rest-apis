Web utility - Temporary links

URL Shortener API

Place a long URL in the request path and get a short 307.fi link. The link works for 24 hours and requires no account or API key.

  • No API key
  • One GET request
  • 307.fi link
  • 24-hour expiry

Create a short URL

GET/url_shortener/{url}

https://aisenseapi.com/services/v1/url_shortener/

Shorten a URL

The target URL goes directly after /url_shortener/. Quote the complete request in a shell so characters such as ? and & are passed correctly.

curl "https://aisenseapi.com/services/v1/url_shortener/https://developer.mozilla.org/en-US/docs/Web/HTTP"
{
  "short_url": "https://307.fi/KtNshX2B",
  "expire_timestamp": 1786959715
}

Response fields

FieldTypeDescription
short_urlstringThe temporary redirect URL on 307.fi.
expire_timestampintegerUnix timestamp for the end of the 24-hour lifetime.

Store both values if the calling workflow needs to know when the link stops working.

How the redirect works

  1. Send the target URL

    The API forwards it to the 307.fi short-link service.

  2. Receive the short link

    The response contains the short URL and expiry timestamp.

  3. Share or store the result

    Requests to the short URL redirect to the original target during the 24-hour lifetime.

When a temporary short URL helps

Workflow notifications

Keep long result or approval URLs readable in messages.

Temporary documents

Share a short link to content that is useful for one day.

QR code input

Shorten a long address before placing it in a QR code.

Agent output

Return a compact URL when an agent needs to pass a link to a person.

Privacy and limits

The target URL is part of the API request path. Do not place passwords, access tokens or private data in it. Full request paths may appear in service access logs.

The short link expires after 24 hours. It is not intended for permanent links, branded campaigns or availability guarantees. The service-wide limit is 5000 requests per IP per 24 hours.
