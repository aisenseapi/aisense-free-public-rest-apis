Transform utility - PNG and Base64

QR Code API

Generate a PNG QR code from text or a URL. Decode a Base64 image or uploaded QR image back to its original content.

  • No API key
  • Generate and decode
  • JSON or file upload
  • PNG output

Two QR endpoints

POST/qrcode_encode

POST/qrcode_decode

https://aisenseapi.com/services/v1

Generate a QR code

Send the content in a JSON field named payload. This endpoint does not use the data field used by many other transform APIs.

curl -X POST https://aisenseapi.com/services/v1/qrcode_encode \
  -H "Content-Type: application/json" \
  -d '{"payload":"https://aisense.no/free-public-apis"}'
{
  "qrcode_image": "iVBORw0KGgoAAAANSUhEUg...",
  "image_type": "png"
}

qrcode_image contains the PNG file encoded as Base64. Decode that string before saving or displaying the image.

Decode a QR code

Send a Base64 image in the payload field:

curl -X POST https://aisenseapi.com/services/v1/qrcode_decode \
  -H "Content-Type: application/json" \
  -d '{"payload":"iVBORw0KGgoAAAANSUhEUg..."}'
{
  "qrcode_content": "https://aisense.no/free-public-apis"
}

You can also upload the image as multipart/form-data with the field name qrcode_image.

Common uses

Links and forms

Put a URL into a scannable image for print, signage or a device screen.

Device setup

Encode short configuration values for a camera or mobile app to read.

Document processing

Extract the value from a QR code attached to a submitted document.

Workflow hand-off

Move a URL or identifier from a digital process to a person with a phone.

Security and limits

A QR code is an encoding format. It does not encrypt or protect its content. Anyone who can scan the image can read the payload.

Check decoded URLs before opening them. Treat QR input from an unknown source in the same way as any other untrusted user input. The service-wide limit is 5000 requests per IP per 24 hours.
