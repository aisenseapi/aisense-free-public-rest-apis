IP geolocation - Local database lookup

IP Reverse Lookup API

Send an IPv4 address and receive country, city, coordinates, place and timezone data as JSON. The lookup runs against local geolocation databases.

  • No API key
  • JSON response
  • Local lookup
  • CORS enabled

Look up an IPv4 address

GET/ip_reverse_lookup/{ip}

https://aisenseapi.com/services/v1/ip_reverse_lookup/8.8.8.8

Look up an IP address

curl https://aisenseapi.com/services/v1/ip_reverse_lookup/8.8.8.8
{
  "ip": "8.8.8.8",
  "country": "United States",
  "city": null,
  "location": {
    "lat": "37.751000",
    "lng": "-97.822000"
  },
  "place": null,
  "timezone": "America/Chicago"
}

Response fields

FieldTypeDescription
ipstringThe address that was looked up.
countrystringCountry name.
citystring or nullCity name when the database has a city-level match.
location.latstringLatitude. The JSON value is a string.
location.lngstringLongitude. The JSON value is a string.
placestring or nullA more specific place name when available.
timezonestring or nullIANA timezone identifier such as America/Chicago.

How to read the result

IP geolocation is approximate. city and place are often null. When a city is unknown, the coordinates may fall back to the country centroid. Do not treat the response as a street address or precise device location.

The endpoint uses local MaxMind and DB-IP database files. The queried address is not sent to an external geolocation API.

Common uses

Timezone defaults

Choose a likely timezone before asking a user to confirm it.

Regional content

Select a country-level default for language, currency or support routing.

Log enrichment

Add approximate country and timezone fields to operational data.

Risk signals

Use country-level context as one input in a wider review process.

Input and limits

Place one IPv4 address in the path. The current route is designed for IPv4 addresses. The service-wide limit is 5000 requests per IP per 24 hours.

Do not use IP geolocation alone for identity, legal location, fraud decisions or access control. Network routing, VPNs and mobile carriers can make the result differ from the user's physical location.
