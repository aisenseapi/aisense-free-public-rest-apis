Webhook Capture API

Create a temporary endpoint, point any webhook sender at it and read back the complete HTTP request - without running a server, opening a tunnel or creating an account.

  • No API key
  • Any HTTP method
  • 24-hour expiry
  • CORS enabled

Create a capture session

POST/webhook_capture

https://aisenseapi.com/services/v1/webhook_capture

How webhook capture works

A capture session gives you two unique URLs: an update_url that receives the webhook and a read_url that returns the captured request as JSON. The session expires automatically after 24 hours.

  1. Create a session

    Send an empty POST request and save the returned capture ID and URLs.

  2. Send the webhook

    Configure Stripe, GitHub, Shopify or any other sender to call the unique update URL.

  3. Inspect the request

    GET the read URL to see the method, URI, headers, client IP and parsed body.

Quick start

# 1. Create a capture session
curl -X POST https://aisenseapi.com/services/v1/webhook_capture

# 2. Send anything to the returned update_url
curl -X POST "{update_url}" \
  -H "Content-Type: application/json" \
  -H "X-Example-Signature: test-123" \
  -d '{"event":"payment.created","amount":4200}'

# 3. Read the captured request
curl "{read_url}"

Create response

{
  "ok": true,
  "capture_id": "6f8c9e52-3f2c-4e73-9d3b-8d6c3f6d1c91",
  "update_url": "https://aisenseapi.com/services/v1/webhook_capture/6f8c9e52-.../update",
  "read_url": "https://aisenseapi.com/services/v1/webhook_capture/6f8c9e52-...",
  "expire_timestamp": 1772893200
}

Captured request format

{
  "ok": true,
  "capture_id": "6f8c9e52-...",
  "captured_at_timestamp": 1786873316,
  "captured_at_datetime": "2026-08-16T09:41:56Z",
  "request": {
    "method": "POST",
    "uri": "/services/v1/webhook_capture/6f8c9e52-.../update",
    "headers": { "content-type": "application/json" },
    "client_ip": "203.0.113.10",
    "body": {
      "json": { "event": "payment.created", "amount": 4200 },
      "text": null,
      "base64": null,
      "raw_length": 45
    }
  }
}
FieldWhat it contains
request.methodThe inbound HTTP method, including POST, PUT, PATCH or DELETE.
request.headersThe request headers received by the capture endpoint.
request.client_ipThe sender's IP address as seen by the service.
request.body.jsonThe parsed value when the body contains valid JSON.
request.body.textText content when the body is not JSON.
request.body.base64Binary content represented safely as Base64.

When to use it

Webhook debugging

Compare what a provider actually sends with what its documentation claims.

Integration setup

Capture a real sample before implementing validation and event handling.

Signature inspection

See which signature headers arrive and how the raw body is represented.

Agent workflows

Give an automated process a temporary callback URL and inspect the result later.

Security, privacy and limits

Do not send production secrets unless you intend to store them temporarily. Webhook Capture records all headers and the complete body. Authorization tokens and signatures sent by a provider will therefore be part of the capture.

Capture data becomes unreachable after 24 hours. The service-wide limit is 5000 requests per IP per 24 hours. No API key is required, so possession of the unguessable read URL is what grants access to a capture.
