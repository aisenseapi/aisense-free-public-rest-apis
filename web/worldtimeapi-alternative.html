Time - WorldTimeAPI

Free WorldTimeAPI Alternative

WorldTimeAPI was the clock behind a great many ESP32 sketches, Arduino projects, games and scripts, and on 3 October 2026 it did not answer us: every connection we made to worldtimeapi.org, over HTTP and HTTPS, was reset. Its fifteen fields answer here, free and without a key, and its own path follows our prefix. Replace the start of the URL, keep the rest.

  • No API key
  • Same fifteen fields
  • Its path after our prefix
  • JSON or .txt

Time in a zone

GET/worldtime/timezone/Europe/Oslo

https://aisenseapi.com/services/v1/worldtime/timezone/Europe/Oslo

One more change is not optional: this host answers HTTPS only. A sketch that fetched http://worldtimeapi.org over a plain WiFiClient has to use https:// and a WiFiClientSecure, shown below.

The fifteen fields

FieldTypeMeaning
abbreviationstringThe local abbreviation, such as CEST, EDT or IST, or a numeric one such as -03 where the database has no letters.
client_ipstringThe address the request came from, also on /worldtime/ip/{address}.
datetimestringLocal date and time, ISO 8601 with microseconds and the offset.
day_of_weekinteger0 for Sunday to 6 for Saturday.
day_of_yearintegerLocal day of the year, starting at 1.
dstbooleanWhether summer time is in force.
dst_fromstring or nullWhen the current summer time period began, in UTC. null when dst is false.
dst_offsetintegerSeconds summer time adds now: 3600 almost everywhere, 1800 on Lord Howe Island, 0 outside summer time.
dst_untilstring or nullWhen the current summer time period ends, in UTC. null when dst is false.
raw_offsetintegerThe standard offset from UTC in seconds, without summer time.
timezonestringThe zone name in its usual case. Old names such as Europe/Kiev are accepted.
unixtimeintegerSeconds since 1970-01-01 UTC.
utc_datetimestringThe same moment in UTC, ending in +00:00.
utc_offsetstringThe offset in force now, as +HH:MM, summer time included.
week_numberintegerThe ISO 8601 week.

The names, types and meanings are WorldTimeAPI's, and so is the order, alphabetical. Slashes in zone names are not escaped, so code that looks for Europe/Oslo in the body as text still finds it.

On an ESP32

The usual sketch called http.begin("http://worldtimeapi.org/api/timezone/Europe/Oslo"). Over HTTPS the call takes a secure client. This short example skips certificate verification. The connection is encrypted, but the server is not authenticated and the time could be forged. Use CA certificate verification when your application needs to trust the returned time:

#include <WiFiClientSecure.h>
#include <HTTPClient.h>

WiFiClientSecure client;
client.setInsecure();          // or client.setCACert(...) to check the certificate

HTTPClient http;
http.begin(client, "https://aisenseapi.com/services/v1/worldtime/timezone/Europe/Oslo");
int code = http.GET();
String body = http.getString();
http.end();

Parsing does not change: the fields are the ones the sketch already reads. For an ESP8266 the class is BearSSL::WiFiClientSecure with the same setInsecure().

Where the answers come from

Zone names and their rules come from the IANA time zone database bundled with the server, which is updated with its releases. Each server worker keeps address lookup results in memory, keyed by IP address. A result is reused for up to an hour, or ten minutes when no zone was found. Expired entries can stay in memory until replaced, removed to make room, or the worker restarts. Not every address has a zone; one without answers 404 rather than a guess, and asking by zone name is the way around it. Requests are logged with the caller's IP address and URL path, as well as status and response time.

If you only need a zone you already know, /datetime/Europe/Oslo answers a shorter object with the offset in force and whether summer time is on.

Privacy and limits

The address in /worldtime/ip/{address} is held in the memory cache and can also appear in request logs. See our privacy policy for log retention. IP-based time zones are approximate and may differ from the device's location.

Every path shares the service-wide ceiling of 5000 requests per IP address per day. No key, no account and no sign-up. The whole catalogue is on Free public REST APIs.
