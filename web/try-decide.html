Pick an example or fill in your own facts and rules. The request is written for you as JSON, and you can edit it. Press Decide to read the answer in plain words and as JSON.

Decide is a free API that answers a question from facts you send. With rules you say what pushes the answer which way, and Decide adds it up to a probability, how clear-cut the weights are, and a next step for the answer it gives. With a decision model, Clef, Nimble or Tev1, you describe the situation in words instead. The request goes from this page straight to https://aisenseapi.com/services/v1/decide. With rules the API keeps neither the request nor the answer. As on every endpoint, the access log records each request with your address, and the daily request limit counts requests per address. A model call also sends the situation and the questions to the model for processing, and counts against the model's own usage limit, which keeps a hash of your address and the timings. See the privacy page.

A model call sends what you write to the model for processing, so leave out personal and confidential details. Model calls have their own limit per address, and Tev1, the smallest and fastest, takes requests up to 3 KiB, was tested in English only and suits short, direct questions. The answer is the model's own and can be wrong, so keep a person in the loop for anything that matters.
