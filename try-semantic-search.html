Try semantic search with your own notes

Pick an example or write your own notes, then search them in your own words. The page shows the JSON it sends, and nothing is sent until you press a button.

Loading the form...

Semantic Search is a free API that keeps short notes in a collection for 24 hours and ranks them by meaning for each search, also when the words differ. This page sends your notes and searches from this tab straight to https://aisenseapi.com/services/v1/semantic_search. The collection's read and write tokens stay in this tab's memory only. Reloading or closing the page loses its access, but does not delete the notes on the server. As on every endpoint, the access log records each request with your address, and the request limits count per address. See the privacy page.

1. Choose an example, or start blank

Each example fills in a few notes and some searches to try. Change them as you like, or start blank and write your own.

2. Write the notes

This test takes up to 8 notes of up to 2000 characters each. The API itself takes up to 32 notes in one call and 500 over a collection's lifetime. A key is an optional label that comes back with each result, such as an order number. It does not stop the same note from being stored twice.

The model is fixed for the collection. To compare the two, run the test again with the other one.

3. The requests, written for you

This is what the page sends. The notes follow what you fill in above, and you can edit their JSON here as well. The tokens stay in this tab and are written here as WRITE_TOKEN and READ_TOKEN.

Create the collection

Add the notes

Your notes are stored and processed for search. The collection expires 24 hours after creation. Searches do not extend it. Leave out passwords, API keys and sensitive personal information. See our privacy page.

4. Search

Pick a search to fill in, or write your own. The last one matches none of the example notes on purpose: a search always ranks the notes there are, so read the text before you trust the first one.
